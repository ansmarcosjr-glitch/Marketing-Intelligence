# Marketing Intelligence — Mapeamento de Mercado

Pipeline de inteligência competitiva para acompanhar preços, sortimento e
demanda de mercado de forma contínua e automatizada.

## Problema

Decisões de precificação e portfólio em e-commerce exigem monitoramento constante
da concorrência — um processo manual, lento e difícil de escalar por categoria.

## Solução

Scraper modular (roda standalone ou orquestrado) que mapeia preços de
concorrentes e calcula um índice de precificação (IP) próprio, combinado com
dados de volume de busca por palavra-chave para leitura de demanda. Arquitetura
desenhada para ser reutilizável entre marcas, sem valores fixos no código.

## Stack

Python · Web scraping · Google Trends

## Status

andamento.
